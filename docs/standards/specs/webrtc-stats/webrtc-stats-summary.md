# WebRTC Stats Summary (TR)

Source: <https://www.w3.org/TR/webrtc-stats/>

## High-Value Areas for WebRtcNet.Api

1. `RTCStatsReport` object model and report graph semantics.
2. RTP stream stats dictionaries:
	- `RTCInboundRtpStreamStats`
	- `RTCOutboundRtpStreamStats`
3. Transport/connection quality dictionaries:
	- `RTCTransportStats`
	- candidate pair and ICE-related stats objects.
4. Timestamp/unit conventions and dictionary evolution patterns.

## Key Anchors and Terms

- `RTCStatsReport`
- `RTCInboundRtpStreamStats`
- `RTCOutboundRtpStreamStats`
- `RTCTransportStats`
