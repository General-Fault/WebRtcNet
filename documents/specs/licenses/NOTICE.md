## Local Storage Purpose

- Stable, local reference for implementation work.
- Faster section lookup and citation for API alignment.

## Modification Policy

- Canonical `TR-*.html` files are stored as fetched snapshots.
- Any transformed or derived artifacts (summaries, IDL extracts, maps) are tracked separately and should identify their source.
