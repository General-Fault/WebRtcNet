# WebRTC 1.0 Summary (TR)

Source: <https://www.w3.org/TR/webrtc/>

## High-Value Areas for WebRtcNet.Api

1. `RTCPeerConnection` core construction, lifecycle, signaling, and state transitions.
2. ICE candidate model, candidate events, and ICE transport policy/configuration.
3. RTP sender/receiver/transceiver interfaces and parameter dictionaries.
4. Data channel creation, states, events, and binary type/message handling.
5. Stats collection entry point (`getStats`) and report integration with WebRTC Stats.
